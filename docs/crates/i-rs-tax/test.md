# i-rs-tax 测试记录

## 测试环境

- macOS
- 数据存储: `~/.config/i-rs/tax.json`

## 功能测试

### 1. 添加个人所得税记录

```bash
$ i-rs-tax add 个税测试2024 \
  --tax-type personal \
  --amount 5000 \
  --date 2024-05-10 \
  --status unreported \
  --tag 测试 \
  --tag 工资

已添加税务记录 '个税测试2024'
```

### 2. 添加增值税记录

```bash
$ i-rs-tax add 增值税测试Q1 \
  --tax-type vat \
  --amount 3000 \
  --date 2024-03-20 \
  --status filed

已添加税务记录 '增值税测试Q1'
```
