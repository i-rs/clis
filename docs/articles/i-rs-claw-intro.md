# i-rs-claw — 你的 AI 终端数据助理

## 当 CLI 遇上 AI

i-rs 有 70 个工具，覆盖生活的方方面面。但 70 个工具意味着你要记住 70 个命令、70 组参数、70 种输出格式。

i-rs-claw 回答了一个简单的问题：**如果终端能听懂人话呢？**

```bash
# 不用记：
i-rs-weight add 2026-05-16 72.5 --remark "晨跑后"

# 直接说：
> 记录今天体重 72.5，晨跑后测的
```

i-rs-claw 是一个 **TUI（终端界面）AI 个人数据助理**。它把 i-rs CLI 工具集的全部能力封装在一个自然语言接口后面——你说中文，它调工具。

## 它解决了什么问题？

### 忘记命令

i-rs-weight 的 `add` 命令参数顺序是什么？`<DATE>` 在前还是 `<WEIGHT>` 在前？`--remark` 是短选项吗？

不需要记住。i-rs-claw 的 AI 会自动通过 `skill teach` 学习每个工具的正确用法，然后以正确的参数顺序调用。

### 跨工具操作

"记录一下今天体重 72.5，跑了 5 公里，心情很好。"

这在 CLI 层面是三条命令：
```bash
i-rs-weight add 2026-05-16 72.5
i-rs-run add 2026-05-16 5km
i-rs-mood add 2026-05-16 great
```

i-rs-claw 一次理解，顺序执行，汇总结果。

### 数据分析

"这周睡眠质量怎么样？"——AI 调用 `i-rs-sleep list --json`，解析数据，用自然语言告诉你趋势和变化。

## 核心能力

### 即学即用（Learn then Execute）

这是 i-rs-claw 最核心的设计：**AI 不是硬编码了工具用法，而是动态学习**。

当 AI 需要操作某个工具时，它会先执行 `skill teach` 加载该工具的完整文档，然后严格按照文档中的命令和参数调用。这意味着：

- 工具更新后无需更新 i-rs-claw
- 新增工具自动可用
- AI 永远使用正确的参数

### 流式响应

每一个 token 实时推送到终端，无需等待完整响应。配合语义分段渲染，阅读体验流畅自然。

### 透明工具调用

AI 后端调用了什么工具、传了什么参数、得到了什么结果——都在界面上清晰可见。没有黑箱，没有意外。

### 工具启用管理

你不需要使用全部 70 个工具。i-rs-claw 提供 TUI 配置界面，让你自由启用/禁用工具。禁用的工具不会出现在 AI 的工具索引中，避免不必要的上下文消耗。

### 语音输入（macOS）

集成 [VoiceInput](https://github.com/shibing624/VoiceInput)，按住 Fn 键说话，松开即输入。支持中文、英文及 50+ 语言，完全离线。

### 会话管理

每次对话自动保存为会话文件（`~/.i-rs-claw/claw/sessions/`），支持历史回溯、上下文压缩、智能摘要。

进入 i-rs-claw，你会看到：

```
┌─────────────────────────────────────────────────────────────┐

├─────────────────────────────────────────────────────────────┤
│  [用户] 最近体重怎么样？                                     │
│  [助理] 最近一周你的体重在 72-73kg 之间波动，              │  ← 对话区
│          整体保持稳定...                                      │
│  ┌─ i_rs ─────────────────────────────────────────────┐     │
│  │ tool: weight, cmd: list, args: [--days 7, --json]  │     │  ← 工具调用面板
│  └────────────────────────────────────────────────────┘     │

├─────────────────────────────────────────────────────────────┤
│  > 帮我查一下这个月的支出                     [Fn 语音输入] │  ← 输入栏
├─────────────────────────────────────────────────────────────┤
│  Ctrl+Q 退出  F2 补全  F3 会话  F5 搜索  Ctrl+Shift+C 复制 │  ← 状态栏
└─────────────────────────────────────────────────────────────┘
```

### 快捷键

| 按键 | 功能 |
|------|------|
| `Enter` | 发送消息 |
| `F2` | Tab 补全（工具名、命令） |
| `F3` | 会话管理（新建、切换、删除） |
| `F4` | ASCII 图表（从结果中生成） |
| `F5` | 语义搜索（历史会话） |
| `Ctrl+Shift+C` | 复制 AI 最后一条回复 |
| `Ctrl+Q` / `Ctrl+C` | 退出 |
| `Fn`（按住） | 语音输入（macOS） |

### 配置

一行 `~/.i-rs-claw/config.toml` 即可使用：

```toml
[config]
api_key = "sk-..."                          # LLM API 密钥
base_url = "https://api.openai.com/v1"      # API 地址
model = "gpt-4o-mini"                       # 模型选择
```

支持任意 OpenAI 兼容 API——OpenAI、DeepSeek、OpenRouter、Groq 等。

```toml
[config]
api_key = "sk-..."
base_url = "https://openrouter.ai/api/v1"
model = "deepseek/deepseek-chat"
```

## 它不是又一个 AI 聊天框

市面上 AI 聊天工具很多。但 i-rs-claw 的不同之处在于：

- **它背后是 70 个真实可执行的 CLI 工具** — 不是模拟，不是 API 调用包装，而是真正在本机运行二进制命令
- **你的数据永远在你手中** — 纯 JSON 存储在 `~/.config/i-rs/`，没有云同步，没有数据泄露
- **完全离线可用** — LLM 需要联网，但数据操作全部本地完成
- **即学即用** — 新工具无需等待 i-rs-claw 更新，加上 SKILL.md 就能被 AI 理解和调用

## 写在最后

i-rs 是一组 CLI 工具，i-rs-claw 是它们的 AI 副驾驶。

你可以继续用命令行精确控制每一个操作，也可以在不想记命令的时候，用自然语言告诉 i-rs-claw 你要什么——两种方式，同一份数据，同一个终端。
