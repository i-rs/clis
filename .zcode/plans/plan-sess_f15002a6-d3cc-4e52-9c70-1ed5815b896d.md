# IrsClawAndroid — 原生 Kotlin Android 客户端（对齐 iOS IrsClawApp）

## 目标

在 `apps/IrsClawAndroid/` 用 Kotlin + Jetpack Compose 全功能移植 SwiftUI 版 IrsClawApp（约 6.3k 行 Swift），对接同一 `claw serve` HTTP 后端。applicationId：`me.siwi.irsclaw`。

## 技术选型（对应 iOS 实现）

| iOS | Android | 说明 |
|---|---|---|
| SwiftUI + NavigationSplitView/Stack | Kotlin 2.x + Jetpack Compose (Material 3) + window-size-class | 手机=抽屉导航（仿 iPhone），平板/展开宽度=侧栏双栏（仿 iPad split） |
| URLSession + 手写 SSE 解析 | OkHttp + 手写逐字节 SSE 解析器（纯函数，可单测） | 忠实移植 iOS 解析器：多行 `data:` 用 `\n` 拼接、token 8KB 批量刷新、取消处理 |
| Codable DTO | kotlinx.serialization `@SerialName` snake_case | 完整移植 ChatModels.swift 全部模型 |
| UserDefaults | DataStore Preferences | 沿用同名 key：`backend_configs`/`current_backend_id`/`llm_*`/`app_appearance`/`session_token_usage_v2` |
| MarkdownUI | Markwon (core+tables+linkify) via AndroidView | 流式期间容忍不完整 markdown |
| JSONHighlightView | 自写 Compose AnnotatedString JSON 高亮 | 移植 iOS 配色（key 紫/string 绿/number 蓝/bool 橙） |
| AsyncImage | Coil | image 气泡 |
| Speech 框架语音输入 | SpeechRecognizer（zh-CN 优先） | 录音条 + PulsingDot + 实时转写 |
| 手写 REST client | OkHttp 直调（不引 Retrofit/Hilt） | 与 iOS 一样保持零框架依赖，超时对齐：health 3s / GET·DELETE 10s / POST 60s / SSE 300s |

依赖仅：Compose BOM、activity-compose、navigation-compose、lifecycle、kotlinx-serialization、OkHttp、Markwon、Coil、DataStore。构建配置用 version catalog（libs.versions.toml）；AGP 8.x + compileSdk 35 + minSdk 24。

## 实施步骤（每步一个 commit，风格沿用 `feat(IrsClawAndroid): ...`）

1. **脚手架**：Gradle 工程 + version catalog + wrapper + manifest + 主题 + 图标资源 + 空 MainActivity；`assembleDebug` 通过（先探测 JAVA_HOME/Android Studio JBR/ANDROID_HOME——`tauri android init` 曾在本机成功，SDK 应已就绪）。
2. **数据层**：DTO + SettingsStore + ClawApi + SseParser + 单测。
3. **状态层 + 连接网关**：ClawViewModel、ConnectScreen、健康检查与重连。
4. **聊天 UI**：消息列表、全部气泡类型、markdown/JSON 高亮、输入栏、SSE 流式渲染。
5. **语音输入**：SpeechRecognizer + 录音条 UI。
6. **外壳与 Sessions**：抽屉/双栏自适应、会话列表分组/搜索/删除、agent 切换 chips。
7. **面板**：Tools / Skills / Plugins / Usage 四个面板。
8. **设置**：外观、后端多配置管理、LLM Provider、Agents CRUD、关于页。
9. **收尾**：README、AGENTS.md 客户端矩阵与目录树补条目。

## 验证

- `./gradlew :app:assembleDebug` 0 error；`./gradlew :app:testDebugUnitTest` 全绿（SSE 解析、DTO 解码）。
- 不影响 Rust workspace（纯新增 apps/ 目录，不改 Cargo.toml）。
- 若本机构建工具链缺失（JDK 17/SDK），交付完整代码 + 构建说明，并明确报告未能本地编译验证。

## 边界说明

- 后端契约以 `crates/claw/src/server/routes/` 为准：`POST /api/chat` 返回 SSE 流（token/reasoning/status/tool_executed/image_generated/evaluation/done/error），`{success,data,error}` 包装，全 snake_case。
- 不移植 macOS 专属逻辑（⌘N、窗口最小尺寸）；平板适配走双栏布局。
- 不引入 Hilt/Retrofit 等重框架，保持与 iOS 端同等的极简依赖。
