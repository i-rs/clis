# i-rs-hello

Simple hello world CLI tool.

## Install

```bash
npm install -g @i-rs/i-rs-hello
# or
brew install i-rs/homebrew-tap/i-rs-hello
```

## Usage

```bash
# Basic usage
i-rs-hello

# With name
i-rs-hello --name Alice

# Or use short flag
i-rs-hello -n Bob
```
