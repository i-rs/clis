# i-rs-fs

File system operations CLI tool.

## Install

```bash
npm install -g @i-rs/i-rs-fs
# or
brew install i-rs/homebrew-tap/i-rs-fs
```

## Usage

### Read File

```bash
i-rs-fs read <FILE>
```

### Write File

```bash
i-rs-fs write <FILE> <CONTENT>
```

### Count Lines

```bash
i-rs-fs lines <FILE>
```
